# Hidradenitis Suppurativa Single-Cell Atlas

Analysis code for:

"A Consensus Single-Cell Atlas Reveals a Constrained Set of Dominant Cellular Programs in Hidradenitis Suppurativa"

Sekhon et al., JID Innovations (2026).

## Overview
Integration and analysis of publicly available hidradenitis suppurativa single-cell RNA-seq datasets.

The final atlas contains 84,103 cells from 46 samples across eight studies.

## Data
Publicly available GEO datasets:
GSE154775, GSE155850, GSE175990, GSE212721,
GSE220116, GSE226427, GSE274880, GSE273109.

## Code
Analysis scripts used for preprocessing, quality control, Harmony integration, clustering, and downstream analyses.
